# Alien Invasion — Python Pygame Project

## Project Overview

This project implements an Alien Invasion game using Python and Pygame. It includes a game window, a space background, ship movement, and laser firing.

## Requirements

Python 3.12

Pygame 2.6.1

## Installation

Install the required dependencies from the project directory:

py -3.12 -m pip install -r requirements.txt

## Run the Game

From the project directory, execute:

py -3.12 alien_invasion.py

## Project Structure

alien_invasion.py — Main game implementation

Assets/ — Game images, fonts, and sound assets

requirements.txt — Python dependencies

.gitignore — Excludes generated and local environment files
